This page is observational. "OI-weighted deviation" ranks attention — where large open interest sits against a deviating feed. It is not a liquidation-loss estimate; no conclusion about harm can be drawn from this data alone.

Method — deviation = |oracle − mark| / mark (Hyperliquid public API). Estimated OI notional = open interest (base units: shares for equities, index units for indices) × mark. Grading: red = dev ≥ 20bps and notional > $100.0M; watchlist = dev ≥ 15bps, or notional > $250.0M with dev ≥ 10bps (red takes precedence; watchlist excludes red); trapped = 24h vol < $5.0K with OI > 0; dormant (DEX-level) = every market across the last 96 snapshots (~48h) with OI = 0 and vol < $5.0K (min 24 snapshots; a single zero snapshot implies nothing). Markets with missing/invalid fields are excluded from all grading and listed separately. These are page-specific observation thresholds — not execution guard thresholds; see the library's deviation module (warn 100 / critical 500 bps) for guard semantics.

What this page cannot show — staleness (the snapshot API does not expose feed update timestamps; the library detects it via oracle-change differential in monitor.mjs) and discovery-band position (the protocol's band anchor is not exposed; see the library's bounds module).
